# 🚀 End-to-End Data Analytics Project | Python • MySQL • Power BI

**Turning Raw Data into Actionable Business Insights**

## 📌 Project Overview

This project demonstrates an end-to-end data analytics workflow, transforming raw datasets into meaningful insights that support data-driven decision-making.

Using Python, MySQL, and Power BI, I performed data cleaning, exploratory data analysis (EDA), SQL-based business analysis, and interactive dashboard development. I also prepared a business report and a professional presentation using Gamma to communicate the findings effectively.

**The goal:** Go beyond analyzing data to identify meaningful patterns, evaluate performance, and communicate insights that can support business decisions.

## 🎯 Business Objectives

- Transform raw data into a reliable, analysis-ready dataset.
- Identify trends, patterns, and relationships through EDA.
- Use SQL to answer business questions and extract insights.
- Develop an interactive Power BI dashboard to monitor key performance indicators.
- Translate analytical findings into clear conclusions and actionable recommendations.

## 🔄 End-to-End Project Workflow

**01 — Data Loading & Understanding**

Imported the dataset into Python and examined its structure, dimensions, column types, and data quality.

**02 — Exploratory Data Analysis (EDA)**

Investigated distributions, trends, correlations, and potential anomalies using Python visualizations.

**03 — Data Cleaning & Preparation**

Handled missing values, duplicates, inconsistent formats, and data types where necessary to improve data quality.

**04 — SQL-Based Business Analysis**

Loaded the prepared data into MySQL and used SQL queries, aggregations, filtering, joins, and subqueries where applicable to investigate business questions.

**05 — Data Modeling & Dashboard Development**

Connected the data to Power BI, transformed it using Power Query, established relationships, and created DAX measures and calculated columns where required.

**06 — Business Reporting**

Documented the methodology, important findings, and conclusions in a structured project report.

**07 — Insight Presentation**

Used Gamma to develop a professional presentation communicating the project's objectives, analysis, visual findings, and recommendations.

## ▶️ How to Run the Project

**Prerequisites:** Python 3.x, Jupyter Notebook, MySQL Server, MySQL Workbench, and Power BI Desktop.

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   cd data-analytics-project
   ```

2. Install the Python dependencies:

   ```bash
   pip install pandas numpy matplotlib seaborn sqlalchemy pymysql jupyter
   ```

3. Open the Jupyter Notebook and execute the analysis and cleaning steps.

4. Create the required MySQL database, load the prepared data, and execute the SQL scripts.

5. Open the Power BI `.pbix` file, configure the data source if required, and refresh the dashboard.

6. Review the report and presentation in their respective folders.
